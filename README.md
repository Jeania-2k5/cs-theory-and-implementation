## `Compiler_Design`

- `first()_follow().py`: Calculates the FIRST and FOLLOW sets for grammar symbols.
- `lexical_analysis.py`: Demonstrates lexical analysis by identifying tokens in source input.
- `LL(1)_parsing.py`: Implements or demonstrates LL(1) parsing for context-free grammars.

## `DAA`

Programs covering common sorting, graph, greedy, tree, and dynamic programming algorithms:

- `1_counting_sort.py`: Implements counting sort.
- `2_radix_sort.py`: Implements radix sort using counting sort by digit.
- `3_quick_sort.py`: Implements quick sort.
- `4_heap_sort.py`: Implements heap sort.
- `5_red_black_tree_insertion.py`: Demonstrates insertion in a red-black tree.
- `6_huffman_codes.py`: Generates Huffman codes using a greedy algorithm.
- `7_kruskal_mst.py`: Finds a minimum spanning tree using Kruskal's algorithm.
- `8_dijkstra.py`: Finds shortest paths using Dijkstra's algorithm.
- `9_knapsack_01.py`: Solves the 0/1 knapsack problem with dynamic programming.
- `10_lcs.py`: Finds the longest common subsequence with dynamic programming.

## `ML`

- `Decision_tree.py`: Implements a decision tree machine learning model.
- `KNN.py`: Implements the k-nearest neighbors classification algorithm.
- `Naive_bayes.py`: Implements a Naive Bayes machine learning classifier.
- `Random_forest.py`: Implements a random forest ensemble model.

## `OS`

- `FCFS.c`: Demonstrates first-come, first-served CPU scheduling.
- `fork()_exec().c`: Demonstrates process creation with `fork()` and program execution with `exec()`.

## `Numerical_and_Statistical_Computing`

Numerical methods for finding roots, solving systems of equations, and interpolation:

- `1_bisection_method.py`: Finds a root using the bisection method.
- `2_regula_falsi_method.py`: Finds a root using the regula falsi method.
- `3_newton_raphson_method.py`: Finds a root using the Newton-Raphson method.
- `4_gauss_elimination_method.py`: Solves a system of linear equations using Gaussian elimination.
- `5_jacobi_iteration_method.py`: Solves a system of linear equations using Jacobi iteration.
- `6_gauss_seidel_method.py`: Solves a system of linear equations using Gauss-Seidel iteration.
- `7_newton_forward_interpolation.py`: Estimates values using Newton forward interpolation.
- `8_newton_backward_interpolation.py`: Estimates values using Newton backward interpolation.
